# Project 93: Financial Modelling and Valuation

**Category:** Enterprise AI Automation
**Part of:** AutoMatrixLab

## Overview

I built this platform to turn an income statement and a balance sheet into a forecast and a valuation, with every figure traceable back to the statement it came from. It follows GAAP and IFRS presentation and regulator-style MD&A guidance, and builds valuations from discounted cash flow, multiples and the growth and margin drivers behind them. Company figures are not stored: you bring your own data or use published annual report figures.

The result is an Excel pack that carries the audit trail, so any figure in the forecast or the valuation can be followed back to the line it came from.

Worked example: a forecast, scenarios and an illustrative valuation for Fonterra. This was a personal exercise built on publicly available figures, not work done for Fonterra and not investment advice.

## Tech Stack

Claude in Excel, DCF Valuation, Financial Modelling, Sensitivity Analysis
